# 模型路由 (astrbot_plugin_model_router)

对话模型自动路由:按优先级链接力探查中转站/模型的可用性,自动切换当前会话的对话模型,并沉淀检测数据出状态图。

## 核心规则

- **接力探查**:按优先级链从上往下。前者超过"合格线"(默认 30s)仍无结果,就启动下一个,前者继续跑到"放弃线"(默认 50s)。
- **合格即停**:一旦有模型在合格线内成功返回,立即采用并取消其余,不再发任何请求。
- **全超线取最快**:所有模型都超过合格线时,在成功返回里选延迟最低的(速度优先,不看出身)。
- **全失败不动**:全都报错或超过放弃线时,保持现状等下一轮。
- **切换等价手动**:`set_provider(umo)` 与 `/provider <idx>` 写同一存储,`/provider` 可见;手动覆盖只在两轮检测之间有效("强制归位"开启时)。

## 命令

| 命令 | 作用 |
|---|---|
| `/模型路由` | 立即检测一轮 + 自动切换 + 回状态图 |
| `/模型路由 状态` | 只看最近数据出的状态图,不发任何请求 |
| `/模型路由 绑定` | 把当前会话设为被管理的会话 |
| `/模型路由 开 / 关` | 启停自动检测与自动切换(手动命令不受影响) |

## 状态图

每个模型一行:优先级序号、本轮状态(合格/超线/失败/未测)、延迟、近 7 天可用率、平均延迟、最近 20 次检测条纹(绿=合格 黄=超线 红=失败)。底部显示当前会话模型 vs 路由建议、免检测时段状态、下次自动检测时间。渲染失败自动回退文字摘要。

## 其他

- **免检测时段**:时段内暂停定时检测与自动切换,时段结束那一刻立即补测一轮。支持跨午夜(如 23:00 到 07:00)。
- **切换通知**:默认仅在"当前模型失败导致切换"时通知(`fail_only`);可设全部通知或全静默。
- **长期不可用**:连续失败达到阈值(默认 24 轮 ≈ 1 天)通知一次,之后每再累积同样轮数再提醒,不重复轰炸。
- **自动跳过**(默认关):连续失败 N 轮后日常检测跳过该模型,但每 24h 轻量复测一次以发现恢复。
- 探测为轻量单轮对话("只回复 OK"),找到即停,正常一轮只花 1 次请求的成本。
