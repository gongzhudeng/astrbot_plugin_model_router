# 模型路由 (astrbot_plugin_model_router)

对话模型自动路由:按优先级链接力探查中转站/模型的可用性,自动切换当前会话的对话模型,并沉淀检测数据出状态图。**全程后台静默,不向聊天发送任何通知。**

## 核心规则

- **接力探查**:按优先级链从上往下。前者超过"合格线"(默认 30s)仍无结果,就启动下一个,前者继续跑到"放弃线"(默认 50s)。
- **合格即停**:一旦有模型在合格线内成功返回,立即采用并取消其余,不再发任何请求。
- **全超线取最快**:所有模型都超过合格线时,在成功返回里选延迟最低的(速度优先,不看出身)。
- **全失败不动**:全都报错或超过放弃线时,保持现状等下一轮。
- **切换等价手动**:`set_provider(umo)` 与 `/provider <idx>` 写同一存储,`/provider` 可见;手动覆盖只在两轮检测之间有效("强制归位"开启时)。

## 命令

| 命令 | 作用 |
|---|---|
| `/模型路由` | 立即检测一轮 + 自动切换 + 回状态图 |
| `/模型路由 列表` | 候选列表图:只列优先级链里的模型,带编号、当前标记、上次探测状态 |
| `/模型路由 3` | 按列表编号直接切换当前对话模型(与 `/provider 3` 同款手感) |
| `/模型路由 测 3` | 单独检测 3 号候选(不切换,结果写入历史) |
| `/模型路由 状态` | 只看最近数据出的状态图,不发任何请求 |
| `/模型路由 绑定` | 把当前会话设为被管理的会话 |
| `/模型路由 开 / 关` | 启停自动检测与自动切换(手动命令不受影响) |

## 状态图 / 列表图

**状态图**(`/模型路由`、`/模型路由 状态`):每个模型一行——优先级序号、本轮状态(合格/超线/失败/未测)、延迟、近 7 天可用率、平均延迟、最近 20 次检测条纹。底部显示当前模型 vs 路由建议、免检测时段、下次检测时间。

**列表图**(`/模型路由 列表`):候选清单,带大号编号、"当前使用"标记、上次探测状态与时间,底部提示切换用法。纯读历史数据,不发探测请求。

两图渲染失败都会自动回退为文字版。

## 其他

- **免检测时段**:时段内暂停定时检测与自动切换,时段结束那一刻立即补测一轮。支持跨午夜(如 23:00 到 07:00)。
- **全程静默**:切换、长期不可用等一切信息只写日志(前缀 `[模型路由]`),不发聊天消息,不打断对话。
- **聊天冷却**:定时检测到点时,若当前模型就是链首且距上次成功对话不足 30 分钟,跳过本轮(聊天已验证可用);当前不是链首时照常检测,盯首位恢复后自动归位。
- **救火感知**:对话发生回退(响应实际模型≠会话当前模型)或慢响应(超过独立阈值,默认 30s)时立即探测并切换,不受免检测时段限制,带冷却防风暴。
- **长期不可用**:连续失败达到阈值(默认 24 轮 ≈ 1 天)写一条告警日志,之后每再累积同样轮数再记一次。
- **自动跳过**(默认关):连续失败 N 轮后日常检测跳过该模型,但每 24h 轻量复测一次以发现恢复。
- 探测为轻量单轮对话(只回复 OK),找到即停,正常一轮只花 1 次请求的成本。
